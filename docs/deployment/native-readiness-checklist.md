# Native packaging readiness checklist

Do not start Android, iOS, Huawei or desktop packaging until this gate is complete.

- [ ] Production API stable
- [ ] PostgreSQL verified with migrations, seed and smoke tests
- [ ] Authentication stable
- [ ] Refresh sessions stable
- [ ] Password reset email provider configured
- [ ] Email verification rollout agreed
- [ ] CORS configured for production domains and future native clients
- [ ] Object storage configured
- [ ] Production push strategy selected
- [ ] Deep-link strategy defined
- [ ] Privacy policy prepared
- [ ] Terms/support pages prepared
- [ ] App icon/splash assets prepared
- [ ] Mobile responsive QA complete
- [ ] Offline behavior and PWA fallback verified
- [ ] Error logging/monitoring connected
- [ ] Backup and restore process tested
